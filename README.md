# 🔬 Math & Science Simulations

> Interactive simulations that make abstract concepts tangible for students.

A growing collection of browser-based educational simulations covering mathematics and science. Built for **curiosity-driven learning** — students can adjust parameters, observe real-time changes, and develop intuition through hands-on exploration.

---

## 📚 Simulation Categories

### 📐 Mathematics
- Function & graph explorers
- Geometry and transformation visualizers
- Calculus (derivatives, integrals, limits)
- Statistics & probability

### ⚗️ Physics
- Kinematics & projectile motion
- Wave and sound simulations
- Optics & ray tracing
- Electromagnetism

### 🧪 Chemistry
- Atomic structure models
- Chemical reaction visualizations
- Periodic table explorer

### 🌍 Earth & Space Science
- Solar system simulator
- Tectonic plate motion
- Climate & atmosphere models

---

## 🚀 Getting Started

All simulations run directly in the browser — no installation needed.

```bash
git clone https://github.com/Kidoarch/math-science-simulations.git
cd math-science-simulations
# Open any .html file in your browser
```
