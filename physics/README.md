# Physics Simulations

Interactive browser-based physics simulations. No installation needed — open any `.html` file directly in your browser.

## Simulations

### 🎯 Projectile Motion (`projectile-motion.html`)
Explore how launch angle, speed, gravity, and launch height affect a projectile's trajectory.

**Learning objectives:**
- Understand how launch angle (45° = maximum range)
- See how initial speed affects range vs. height
- Compare motion under different gravitational fields (Earth, Moon, Mars)
- Observe the independence of horizontal and vertical motion

**Controls:**
| Parameter | Range | Default |
|-----------|-------|---------|
| Launch Angle | 1° – 89° | 45° |
| Initial Speed | 5 – 80 m/s | 30 m/s |
| Gravity | 1 – 25 m/s² | 9.8 m/s² |
| Launch Height | 0 – 50 m | 0 m |

**Suggested explorations:**
1. Which angle gives the greatest range? (Try 30°, 45°, 60°)
2. Set gravity to 1.6 m/s² — how far does it go on the Moon?
3. What happens to range if you double the speed?
